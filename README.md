# Trening za decu

A bodyweight training app for a 10-year-old, built from the same structure as `training-app`. The interface is in Serbian (Latin script). It works offline and installs to the home screen on Android and iPad.

## What it does
- **Gde treniraš danas?** Pick **Unutra** (quiet, a small patch of floor next to a chair, at most one quiet jump) or **Napolju** (2 to 4 jumping or running exercises).
- Each workout has 6 to 8 exercises covering legs, upper body (including the chair), core and balance. It is reshuffled every time and avoids the exercises from the last workout.
- Sets are logged in reps (*ponavljanja*) or seconds (*sekundi*). Limits: 15 reps and 60 seconds per set.
- Green tick boxes for sets and a red X to delete extra sets (minimum 3).
- 1-minute rest timer with vibration, one low ding and a mute button.
- Countdown timer for timed exercises. For exercises done on each leg or side, it gives a "change leg" signal halfway.
- Goals of 3 workouts per week and 12 per month, full history, a workout counter starting at 1, and backup/restore.
- Every exercise has its own illustration in `/images`. The large picture moves between start and end position (`/images/anim`), unless the device asks for reduced motion. Tap the exercise name to see the description.
- A guided 2–3 minute warm-up before the first exercise, which can be skipped.
- A "Spremi se 3, 2, 1" countdown before timed exercises and beeps in the last 3 seconds.
- Records, an end-of-workout celebration and medals. When an exercise has been at the top limit two workouts in a row, the app offers the harder version.
- Adjustable rest (between sets and before the next exercise), an estimated workout length, a "Za roditelje" summary and a backup reminder.
- In Podešavanja: the app version, **Proveri ažuriranja** (loads the newest version right away) and **Podeli** (a QR code another phone or tablet can scan, plus send/copy link).

## Files
- `index.html`: the whole app, including the exercise list (`EX` near the top of the script)
- `images/*.svg`: exercise illustrations, generated by `python3 tools/make_images.py`
- `fonts/`: Inter, self-hosted (SIL Open Font License, see `fonts/OFL.txt`)
- `qr.js`: QR code generator, copied from the Gitara app
- `sw.js`, `manifest.webmanifest`, `icons/`: offline support and the home screen install

## Releasing a new version
Run `python3 tools/release.py` before pushing. It raises the version shown in the app and the cache name in `sw.js`, which is what lets "Proveri ažuriranja" find the new version.

## Publishing on GitHub Pages
Settings → Pages → Deploy from a branch → `main`, folder `/ (root)`.
